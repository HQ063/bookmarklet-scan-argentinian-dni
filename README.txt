1. Crear repo público bookmarklet-scan-argentinian-dni
2. Subir dni-scanner.js en la raíz del repositorio.
3. Settings > Pages > Deploy from a branch > main / (root).
4. Verificar https://TU-USUARIO.github.io/bookmarklet-scan-argentinian-dni/dni-scanner.js
5. Reemplazar TU-USUARIO en bookmarklet-loader-github-pages.txt por tu usuario GitHub.
6. Copiar la línea completa como URL de un favorito de Chrome.

Nota: si la página bloquea scripts externos mediante CSP, el loader puede no funcionar.
